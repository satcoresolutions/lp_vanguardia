# Changelog

Todos los cambios importantes de **Landing Page Vanguardia** de SatCore Solutions se documentarán en este archivo.

El formato está organizado por versiones y categorías de cambios, siguiendo una estructura basada en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/).

Las categorías utilizadas son:

- **Added:** nuevas funcionalidades.
- **Changed:** cambios en funcionalidades existentes.
- **Deprecated:** funcionalidades que se marcarán para eliminación futura.
- **Removed:** funcionalidades eliminadas.
- **Fixed:** correcciones de errores.
- **Security:** cambios relacionados con la seguridad.

## [1.0.0] - Por determinar

### Added

- Estructura inicial de Landing Page Vanguardia.
- Configuración base de Next.js y TypeScript.
- Integración de Tailwind CSS para la construcción de interfaces.
- Organización de componentes reutilizables en las capas `ui` y `sections`.
- Componente de navegación principal.
- Sección Hero para la presentación de la propuesta de valor.
- Sección de características y beneficios.
- Estructura para la presentación de productos.
- Componentes para prueba social y testimonios.
- Sección de llamada a la acción.
- Componente de pie de página.
- Componentes compartidos para botones, insignias, tarjetas de productos y etiquetas de sección.
- Componente de acceso a WhatsApp.
- Organización de recursos gráficos por categorías.
- Utilidad compartida para la lógica común de la interfaz.
- Configuración de estilos globales.
- Configuración de ESLint para apoyar la calidad del código.

## Convenciones de versionado

Las versiones deben actualizarse de acuerdo con la magnitud de los cambios:

- **MAJOR:** cambios incompatibles con versiones anteriores.
- **MINOR:** incorporación de funcionalidades compatibles.
- **PATCH:** correcciones de errores compatibles.

Las fechas y las versiones deben corresponder a lanzamientos reales. No se debe asignar una fecha de publicación hasta que la versión haya sido confirmada.
